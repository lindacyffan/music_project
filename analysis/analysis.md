## 结论2：高赞评论的共同特征：情感共鸣与幽默调侃
* 方法说明：从爬取的歌曲评论数据中，按点赞数排序取前 100 条作为`高赞组`，同时从全部评论中随机抽取 100 条作为`对照组`，使用智谱 AI API 对每条评论进行类型分类。
* 类型选择：情感共鸣、幽默调侃、哲理文化、粉丝支持、科普信息、其他
* 统计结果：![alt text](comment_type_pie.png)
* 对比分析：![alt text](comment_type_comparison.png)
* 情感共鸣类评论在高赞组中占比最高（48%），显著高于随机组的 37%：差值达 11 个百分点，说明能引发听众情感共鸣的评论最容易获得高点赞数。
## 结论3：不同场景歌单语气词密度存在明显差异
* 公式：语气词密度 = 语气词出现次数 / 歌词总字数
* 举例：统计了以下语气词`啊、哦、喔、嗯、啦、吧、吗、呢、呀、哇、嘿、哈、呵、唉、哎、噢、哼、唔、咦、呗、咯、哟、喽、嘛、耶`
* 结论：跑步听华语和旅行听华语歌单的语气词密度相近（约 0.0068），显著高于通勤好状态（0.00123），差异达 5.5 倍。
